# 2-1 승인 게이트 — 안 써본 기능 7차 시연용 그림 바로잡기

- 일시: 2026-11-15
- 결과: 사용자 승인("승인, 추천대로"). 세 앱(안 써본 기능, 같은편, DRIVE DNA)을 한 게이트에서 함께 승인받았다.
- 근거로 보인 것: 시연용 그림 검토 결과, 앱별 실사용 변화와 잃는 것(DNA 칸 128dp), Figma 페이지 "시연용 그림 7차 (1114)" 프레임 ⑰~㉔(https://www.figma.com/design/mme1NBmcgJhFEvmRzMh4IB/?node-id=31-69), goldfish 요약(세 앱 다시 쓰기 원문, 판정, 집계), 소요 시간(약 3시간: 구현 40분, 에뮬레이터 확인 1시간, 점검·리뷰 1시간, PR·머지 30분).
- 세 앱 공통 결정:
  - 내부 확인용 주행 영상은 다시 녹화하지 않는다. 바뀐 그림은 캡처로 확인하고, 제출 영상은 사용자가 7차 코드로 새로 녹화한다.
  - 마무리는 저장소마다 PR → Claude 코드 리뷰 CI 확인·반영 → 머지까지 한다.
  - 에뮬레이터는 메인 세션이 세 앱을 차례로 쓰고, 셋이 다 끝난 뒤 한 번 끈다.
- 이 앱의 사용자 결정:
  - 화면 코드가 그대로라 impeccable audit 대신 캡처 두 장으로 확인한다(research R4).
  - goldfish 절차 보강 셋을 넣는다: 에뮬레이터는 한 곳에서 차례로, 리뷰 반영 뒤 테스트·빌드 다시(T010b), 캡처가 어긋나면 고치지 말고 보고하고 멈춤(T008).
- goldfish: 지적 12개 중 6개를 문서에 반영, readiness GO
- 범위: 설계 docs/superpowers/specs/2026-11-14-demo-pictures-design.md U1과 이 폴더의 spec·plan·research·quickstart·tasks.

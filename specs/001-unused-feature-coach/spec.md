## User Scenarios & Testing *(mandatory)*

### User Story 1 - 운전이 끝나면 놓친 기능 하나를 듣는다 (Priority: P1)

운전자가 운전을 마치고 기어를 P에 놓습니다. 이번 운전에서 쓸 기회가 있었는데 쓰지 않은 차 기능이 있으면, 차가 그중 하나를 짧은 음성으로 알려 주고 화면에 카드로 남깁니다. 카드에는 기능 이름, 이번 운전에서 왜 이 기능이 떠올랐는지, 버튼 위치·쓰는 법이 있습니다.

**Why this priority**: 이것이 앱의 전부입니다. 이 흐름만 있어도 "기능을 모르고 지나치는" 문제를 다룹니다.

**Independent Test**: 기어를 D로 두고 풍량을 손으로 세 번 바꾼 뒤 P로 바꾸면, "공조 AUTO" 안내가 음성과 카드로 나오는지 봅니다.

**Acceptance Scenarios**:

1. **Given** 운전자가 1분 넘게 주행하며 풍량·온도를 손으로 3번 이상 바꾸고 AUTO는 켜지 않았을 때, **When** 기어를 P로 바꾸면, **Then** "공조 AUTO" 안내가 한 문장 음성으로 나오고 화면 카드에 이유와 쓰는 법이 보입니다.
2. **Given** 이번 운전에서 놓친 기능이 둘 이상일 때, **When** P로 바꾸면, **Then** 하나만 안내합니다.
3. **Given** 이번 운전에서 놓친 기능이 없을 때, **When** P로 바꾸면, **Then** 아무 말도 하지 않습니다.
4. **Given** 운전자가 주행 중일 때, **Then** 어떤 안내도 나오지 않습니다.

---

### User Story 2 - 써 본 기능은 다시 듣지 않는다 (Priority: P2)

운전자가 안내받은 기능(또는 원래 알던 기능)을 실제로 쓰면, 앱이 차 신호로 이를 알아채고 "익힘"으로 표시합니다. 그 기능은 다시 안내하지 않습니다. 안내받은 뒤 써 본 경우에는 다음 정차 때 카드에 "써 보셨네요" 확인이 함께 보입니다.

**Why this priority**: 이미 아는 것을 계속 알려 주면 잔소리가 되어 앱을 끕니다. 또 안내 → 실제 사용으로 이어진 것을 보여 주는 것이 이 앱의 효과 증거입니다.

**Independent Test**: "공조 AUTO" 안내를 받은 뒤 다음 운전에서 AUTO를 켜고 P로 바꾸면, 카드에 익힘 확인이 보이고 이후 AUTO 안내가 다시 나오지 않는지 봅니다.

**Acceptance Scenarios**:

1. **Given** "공조 AUTO"를 안내받았을 때, **When** 다음 운전에서 AUTO를 켜고 P로 바꾸면, **Then** 카드에 "공조 AUTO, 써 보셨네요"가 보이고 기능 목록에서 공조 AUTO가 익힘이 됩니다.
2. **Given** 안내받은 적 없는 기능을 운전자가 원래 쓰고 있을 때, **When** 그 사용 신호가 오면, **Then** 그 기능은 익힘이 되고 앞으로 안내 후보에서 빠집니다.
3. **Given** 같은 기능을 3번 안내했는데 여전히 쓰지 않을 때, **Then** 그 기능은 더 안내하지 않습니다.

---

### User Story 3 - 내 차 기능 현황을 본다 (Priority: P3)

정차 중 앱을 열면 지금까지 다룬 기능들이 익힘 / 안내함(횟수) / 아직 상태로 보입니다.

**Why this priority**: 시연과 기획 설명에 필요하지만, 없어도 P1·P2는 동작합니다.

**Independent Test**: 앱을 열어 기능 6개와 각 상태가 보이는지 확인합니다.

**Acceptance Scenarios**:

1. **Given** 앱을 처음 설치했을 때, **When** 앱을 열면, **Then** 기능 6개가 모두 "아직"으로 보이고 마지막 안내 카드 자리에 "첫 운전이 끝나면 여기에 안내가 나와요"가 보입니다.
2. **Given** 안내와 익힘 기록이 있을 때, **When** 앱을 열면, **Then** 각 기능의 상태가 기록과 일치합니다.

### Edge Cases

- 주행이 1분 미만이면(주차 위치만 고침) 운전으로 세지 않고 안내하지 않습니다.
- 차가 어떤 기능 신호를 주지 않으면(그 기능이 없는 차, 구독 실패) 그 기능은 기회 조건이 성립하지 않아 안내하지 않습니다.
- 음성 엔진이 실패해도 카드와 알림은 남습니다.
- 운전 중 앱 프로세스가 다시 시작되면 그 운전의 기록은 버리고 다음 운전부터 셉니다.
- P에서 P가 아닌 기어로, 다시 P로 여러 번 오가면 각 P 전환이 운전 끝이 될 수 있지만, 1분 규칙으로 짧은 이동은 걸러집니다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 기어가 P에서 다른 기어로 바뀐 순간부터 다시 P가 될 때까지를 한 번의 운전으로 본다.
- **FR-002**: 시스템은 운전이 1분 이상일 때만 운전 끝 판단을 한다.
- **FR-003**: 시스템은 운전 중 아래 기능별 "기회" 조건과 "사용" 신호를 센다.
  - 공조 AUTO: 기회 = 풍량 또는 설정 온도를 손으로 합쳐 3번 이상 바꿈 / 사용 = AUTO 켜짐
  - 동승석 개별 온도: 기회 = 조수석 착좌 + 설정 온도를 1번 이상 바꿈 / 사용 = DUAL 켜짐
  - 운전대 열선: 기회 = 운전석 시트 열선 켜짐 / 사용 = 운전대 열선 켜짐
  - 통풍 시트: 기회 = 에어컨 켜짐 + 설정 온도 21℃ 이하 + 시트 열선을 켜지 않음 / 사용 = 운전석 통풍 켜짐
  - 오토 라이트: 기회 = 전조등 켜짐·꺼짐 변화 2번 이상 + 그때 스위치가 AUTO가 아님 / 사용 = 전조등 스위치 AUTO
  - 크루즈 컨트롤: 기회 = 이번 운전이 20분 이상 / 사용 = 크루즈 작동(속도 유지 중)
- **FR-004**: 시스템은 운전 끝에, 기회는 있었고 이번 운전에서 쓰지 않았으며 익힘이 아니고 안내 횟수가 3번 미만인 기능 가운데 하나를 고른다. 안내 횟수가 가장 적은 것을 먼저, 같으면 FR-003의 순서로 고른다.
- **FR-005**: 시스템은 고른 기능을 한 문장 음성과 시스템 알림, 앱 카드로 알리고 그 기능의 안내 횟수를 1 올린다.
- **FR-006**: 시스템은 어떤 기능의 사용 신호를 받으면 그 기능을 익힘으로 기록하고, 이후 안내 후보에서 뺀다.
- **FR-007**: 안내한 적 있는 기능이 이번 운전에서 익힘이 되면, 운전 끝 카드에 "써 보셨네요" 확인을 함께 보인다.
- **FR-008**: 시스템은 주행 중(P가 아닐 때) 음성·알림·카드 갱신을 하지 않는다.
- **FR-009**: 시스템은 사용자가 앱을 열지 않아도 차가 켜져 있는 동안 운전을 지켜본다(부팅 후 자동 시작 포함).
- **FR-010**: 앱 화면은 마지막 안내 카드와 기능 6개의 상태(익힘 / 안내함 n회 / 아직)를 보여 준다.
- **FR-011**: 기록(기능별 안내 횟수, 익힘 여부, 마지막 안내)은 기기 안에만 저장하고 앱을 다시 시작해도 유지한다.

### Key Entities

- **운전(Drive)**: P → 다른 기어 → P 사이. 시작 시각, 길이, 기능별 기회·사용 집계를 가진다. 저장하지 않는다.
- **기능(Feature)**: 이름, 안내 문장, 쓰는 법, 기회 조건, 사용 조건. 6개 고정.
- **진행 기록(Progress)**: 기능별 안내 횟수와 익힘 여부, 마지막 안내 결과. 기기 안에 저장한다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 기회 조건을 채운 운전 뒤 P로 바꾸면 3초 안에 안내가 시작된다.
- **SC-002**: 주행 중에는 안내가 0건이다.
- **SC-003**: 익힘이 된 기능은 이후 안내 0건이다.
- **SC-004**: 같은 기능의 안내는 평생 3건을 넘지 않는다.
- **SC-005**: 시연에서 "조작 → P → 안내 → 다음 운전에 사용 → 익힘 확인" 한 바퀴를 3분 안에 보여 줄 수 있다(크루즈 제외).

## Assumptions

- 대상은 Pleos Connect 차량을 처음 몇 달 쓰는 운전자입니다.
- 차속 신호는 Pleos SDK에 없으므로 크루즈 기회는 연속 주행 시간만으로 봅니다.
- 시트 메모리는 SDK에 사용 신호가 없어 첫 버전에서 뺐습니다.
- 운전자는 한 사람으로 봅니다(여러 운전자 구분은 범위 밖).
- 안내 문장의 버튼 위치는 차종마다 다를 수 있어 "화면 공조 메뉴의 AUTO"처럼 일반적으로 씁니다.

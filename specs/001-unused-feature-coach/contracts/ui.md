# UI Contract: 안내 문장과 화면

## 음성 (P 전환 직후, 한 문장)

`"이번 운전에서 <이유 요약>. 다음엔 <기능 이름>을 써 보세요."`

| 기능 | 음성 문장 |
|---|---|
| 공조 AUTO | 이번 운전에서 바람과 온도를 여러 번 손으로 바꾸셨어요. 다음엔 공조 AUTO를 켜 보세요. 알아서 맞춰 줘요. |
| 동승석 개별 온도 | 옆자리에 동승자가 있었어요. DUAL을 켜면 조수석 온도를 따로 맞출 수 있어요. |
| 운전대 열선 | 시트 열선을 켜셨네요. 이 차에는 운전대 열선도 있어요. |
| 통풍 시트 | 에어컨을 낮게 트셨어요. 통풍 시트를 켜면 등이 덜 덥습니다. |
| 오토 라이트 | 전조등을 여러 번 직접 켜고 끄셨어요. 라이트 스위치를 AUTO에 두면 차가 알아서 켜요. |
| 크루즈 컨트롤 | 오래 운전하셨어요. 다음엔 크루즈 컨트롤로 발을 쉬게 해 보세요. |

## 알림

- 제목: `안 써본 기능: <기능 이름>`
- 본문: 음성 문장과 같음. 누르면 앱 화면.

## 화면

1. **마지막 안내 카드**
   - 운전 기록이 없을 때: 제목 "아직 운전 기록이 없어요", "첫 운전이 끝나면 여기에 안내가 나와요."
   - 운전했지만 알릴 기능이 없거나, 마지막 안내를 이미 써 봤을 때: 제목 "지금은 알려 드릴 기능이 없어요", "다음 운전이 끝나면 다시 살펴볼게요."
   - 익힘 확인이 있으면 맨 위에 "<기능 이름>, 써 보셨네요. 이제 다시 알려 드리지 않아요."
   - 기능 이름(제목), 이유 문장, 쓰는 법.
2. **기능 목록** (6줄): `<기능 이름>  익힘 | 안내함 n회 | 아직`
3. **상태 줄**: "운전을 지켜보는 중", "차 연결 실패: <원인>"(10초마다 재시도, 연결되면 사라짐), 또는 "<신호> 신호 없음"(그 기능이 없는 차).

## 쓰는 법 문장 (카드)

| 기능 | 쓰는 법 |
|---|---|
| 공조 AUTO | 공조 화면이나 공조 패널의 AUTO 버튼을 누르세요. 원하는 온도만 정하면 풍량과 바람 방향은 차가 맞춥니다. |
| 동승석 개별 온도 | 공조 화면의 DUAL(또는 SYNC 해제)을 누른 뒤 조수석 온도를 따로 정하세요. |
| 운전대 열선 | 공조 화면이나 운전대 근처의 열선 핸들 버튼을 누르세요. |
| 통풍 시트 | 공조 화면의 시트 통풍 버튼을 누르세요. 단계를 올릴수록 바람이 셉니다. |
| 오토 라이트 | 왼쪽 레버(라이트 스위치)를 AUTO 위치로 돌려 두세요. |
| 크루즈 컨트롤 | 원하는 속도에서 운전대의 크루즈 버튼을 누르고 SET을 누르세요. 브레이크를 밟으면 풀립니다. |

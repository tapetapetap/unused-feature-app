# 승인 게이트: 추천 기록 페이지 (2026-11-09)

## 실사용에서 달라지는 것

| 지금 | 바뀐 뒤 |
|---|---|
| 지도 머리에 진행 원과 "내 차 기능"만 있다 | "추천 기록 n ›" 버튼이 생긴다. 정차 중에만 누를 수 있고, 주행 중에는 흐리게 보이며 눌리지 않는다 |
| 지난 안내는 다음 운전이 끝나면 사라진다 | 안내마다 기록이 남는다. 날짜별 목록으로 다시 보고(최신이 위), 써 본 기능에는 "써 봄 ✓"이 붙는다 |
| 안내 화면의 근거와 누를 곳은 그 순간에만 볼 수 있다 | 목록 항목을 누르면 그때 안내 화면이 그대로 나온다. 제목만 "11월 9일 오후 7:50 운전 · 2분"으로 바뀌고, 지도에는 그 구역 선택 링이 그려진다 |
| — | 기록이 없으면 "아직 추천받은 기능이 없어요"가 나온다 |

## 바뀌지 않는 것

- 언제 무엇을 권하는지(안내 규칙), 음성과 알림 문장
- 기존 상황 화면(첫 실행, 안내, 확인, 권할 것 없음, 도감 완성)과 구역 카드
- 주행 중 규칙: 기록 페이지를 보던 중이라도 기어가 P가 아니면 닫히고 주행 중 화면이 된다

## 기존 사용자가 잃는 것

없다. 다만 이번 버전 전에 받은 안내는 기록 목록에 나오지 않는다(지금 화면의 마지막 안내 포함). 그때는 안내 시각을 저장하지 않았다.

## 시연에 미치는 영향

- `scripts/demo.sh` 시나리오를 돌릴 때마다 기록이 쌓인다.
- `reset`은 기록도 지운다(기록 파일을 지우므로).

## 미리 알 수 없는 것

- 기기 저장소(SharedPreferences XML)가 기록 구분 문자(`\u001E`, `\u001F`)를 그대로 돌려주는지. 구현 첫 단계(Phase 2 체크포인트, 시나리오 7·10)에서 확인한다. 안 되면 구분 문자만 바꾼다. 화면과 동작은 같다.

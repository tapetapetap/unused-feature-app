# 화면 계약: 안 써본 기능 4차

1~3차 화면 계약에 더한다.

## 안내 화면(TIP)

- 제목 영역(hero) 바로 아래에 자막 카드가 있다. 순서: (확인 띠) → "방금 끝난 운전" → hero → 자막 카드 → 근거 카드 → 누를 곳 카드.
- 자막 카드(`Ui.caption(f, title, until)`)
  - 배경: `card` 색, 둥근 18dp, 테두리 `line` 1dp. 안쪽 여백 좌우 24dp, 위아래 18dp
  - 왼쪽: 스피커 아이콘 28dp(`ic_speaker`, `blue`), 그 오른쪽에 소리 막대(`SoundBars`)
  - 오른쪽: 작은 제목(20sp, `text3`, 굵기 600), 그 아래 문장(24sp, `text1`)
  - 작은 제목: 안내 화면은 "방금 들은 음성"(이번에 말하지 못했거나 앱이 새로 떠 말한 기록이 없으면 "안내 음성"), 다시 보기는 "그때 들은 음성"
- 소리 막대(`SoundBars`, 위임 결정 V3)

| 값 | |
|---|---|
| 막대 | 세 개, 폭 5dp, 간격 4dp, 둥근 끝, `blue` |
| 높이 | View 높이 24dp. 움직일 때 막대 높이 = 24dp × (0.3 + 0.7 × (0.5 + 0.5 sin(2π(t/900ms + i/3)))) |
| 위상 | 막대 i(0, 1, 2)마다 1/3 주기씩 다름 |
| 정지 모습 | 높이 40%, 70%, 50% |
| 움직이는 동안 | `uptimeMillis < until`이고 애니메이터가 켜져 있을 때만 |

- 차 지도: 새 안내 동안 추천 구역에 넓은 링이 퍼지고 이름표가 굵다(아래 "강조").

## 추천 기록 다시 보기(RECORD)

- 같은 자막 카드가 있다. 작은 제목은 "그때 들은 음성"이고 막대는 멈춰 있다.

## 추천 기록 목록(HISTORY)

- 카드 오른쪽 끝에 미니 지도(`ZoneThumb`, 72×128dp)가 있다.
  - 차 그림(`car_top`)과 그 기능 구역의 점(지름 14dp, 채움)·링(지름 26dp, 선 2dp)
  - 색: 익힘 `green`, 아직 `blue`, 지원 안 함 `dot_line`(회색). 익힘이 지원 안 함보다 먼저다.

## 차 지도 강조(위임 결정 V1·V5)

- 언제: 안내 화면이고, 앱이 그 안내를 말한 지 10초 안(uptime)
- 움직임 켜짐: 테두리 링 r → 3.4r(1.2초 주기), 두께 3dp, `blue`, 알파 (1 − t) × 200
- 움직임 줄이기: 반지름 r + 6dp, 두께 4dp, `blue` 고정 원
- 둘 다: 구역 이름표 굵기 800, 10초가 지나면 지운다.

# UI Contract: 안 써본 기능 5차 주행 중 화면과 음성

1~4차 contracts 위에 더한다. 글자 크기는 sp, 길이는 dp다(에뮬레이터 1dp = 1px). 문구는 이 문서 그대로 쓴다.

## §1 주행 중 화면(`Ui.driving(recording, live, compact)`)

- 자리: 지금 주행 화면과 같다(가운데 세로 배치).
  - 가로 배치(전체 앱 칸): 위 여백 120dp, 타일 150. 지도 칸은 지금처럼 흐리게 남는다.
  - 세로 배치(내비 옆 작은 칸, `compact`, `layout-port`): 주행 중에는 지도 칸(`mapPane`)을 숨겨(GONE) 상황 화면이 창 높이를 다 쓴다. 위 여백 40dp, 타일 120이다. P가 되면 지도 칸이 다시 보인다.
    - 에뮬레이터의 내비 옆 칸은 1:1 분할의 앱 칸이다(폭 약 697px, research R2).
  - 요소 사이 간격은 세 상태 모두 32dp다(지금 주행 화면 `column(32, …)`과 같다). 타일 크기는 가로 150, 세로 120이다.
  - 글은 줄바꿈된다. 줄이지 않는다. 두 배치 모두 누를 곳 버튼 줄까지 스크롤 없이 보여야 한다.
- 공통: 움직이는 효과가 없다(`pulse`, 애니메이터, 소리 막대 금지). 누를 수 있는 뷰가 없다.

| 상태 | 위에서부터 |
|---|---|
| 기다림(기록하는 운전) | 운전대 타일(`ic_z_wheel`, SOFT) → "운전 중이에요"(60sp) → "쓸 만한 기능이 생기면 한 번 알려 드릴게요."(30sp) → 알약 "주행 중에는 한 운전에 두 번까지만, 짧게 알려요"(22sp `text3`) |
| 기다림(기록하지 않는 운전) | 지금 그대로: "이번 운전은 기록하지 않아요. 다음 운전부터 지켜볼게요." 알약은 위와 같다 |
| 권함 | "지금 쓸 만한 기능"(22sp `text3`) → 기능 타일(`f.icon`, BLUE) → 기능 이름(60sp) → 주행 중 문장(30sp `text2`) → 자리 이름(24sp `text1` 600, 예 "오른쪽 레버") → 버튼 줄(`where(f.where, blink = false)`: 누를 버튼만 파랑, 깜빡이지 않음) |
| 써 봤어요 | 기능 타일(`f.icon`, GREEN, 체크 배지, 크기는 위와 같음) → "써 봤어요"(60sp) → 기능 이름(30sp `text2`). 두 줄이 모두 보이면 이 상태다(SC-002) |

## §2 다시 그리기

- 다시 그리기 키는 data-model §6의 네 값이다. 주행 중에는 키가 바뀔 때만 다시 그린다.
- P가 되면 지금처럼 P 화면(안내·확인·권할 것 없음)이다.

## §3 주행 중 문장(`Feature.live`)

- 글자 수는 공백과 문장 부호를 포함해 40자 이하다(FR-009).
- 표의 위에서 아래 순서가 `Feature` 열거 순서이고, 같은 안내 횟수일 때의 우선순위다(FR-006).

| 기능 | 문장 |
|---|---|
| 공조 AUTO | 바람과 온도를 자주 바꾸셨네요. 공조 AUTO를 켜 보세요. |
| 오토 와이퍼 | 와이퍼를 자주 바꾸셨네요. 레버를 AUTO에 두면 차가 맞춰요. |
| 오토 라이트 | 전조등을 자주 켜고 끄셨네요. 스위치를 AUTO에 두면 알아서 켜요. |
| 하이빔 보조 | 하이빔을 자주 바꾸셨네요. 하이빔 보조를 켜면 차가 바꿔요. |
| 크루즈 컨트롤 | 빠르게 오래 달리셨네요. 크루즈 컨트롤로 발을 쉬게 해 보세요. |
| 시트 열선 | 난방을 높이셨네요. 시트 열선을 켜면 더 빨리 따뜻해져요. |
| 운전대 열선 | 시트 열선을 켜셨네요. 운전대 열선도 있어요. |
| 통풍 시트 | 에어컨을 낮추셨네요. 통풍 시트를 켜면 등이 덜 더워요. |
| 동승석 개별 온도 | 옆자리에 동승자가 있어요. DUAL로 조수석 온도를 따로 맞춰요. |
| 동승석 시트 열선·통풍 | 옆자리에 동승자가 있어요. 조수석 열선·통풍도 따로 켤 수 있어요. |
| 앞유리 김서림 제거 | 비 오는 동안 내기 순환이 길었어요. 김이 서리면 김서림을 누르세요. |
| 뒷유리 열선 | 비 오는 길을 오래 달리셨네요. 뒷유리 열선을 켜면 뒤가 잘 보여요. |
| 사이드미러 열선 | 비 오는 길을 오래 달리셨네요. 미러 열선을 켜면 물방울이 빨리 말라요. |
| 오토 내/외기 | 내기와 외기를 자주 바꾸셨네요. 오토 내/외기를 켜면 차가 바꿔요. |
| MAX A/C | 에어컨을 가장 낮추셨네요. MAX A/C가 가장 빨리 시원해요. |
| 주행 모드 | 고속으로 오래 달리셨네요. ECO 모드로 바꾸면 전비가 좋아져요. |
| 뒷좌석 시트 열선 | (없음: 주행 중에 권하지 않는다) |
| 앰비언트 라이트 | (없음: 주행 중에 권하지 않는다) |

## §4 음성

- 권할 때 위 문장을 한 번 말한다(지금 `speak`, 큐에 넣지 않고 바로).
- 써 봤어요는 말하지 않는다.
- 말하지 못했으면(엔진 준비 안 됨, 실패) 로그만 남기고 화면은 그대로 바뀐다.
- P 안내 음성·자막·소리 막대(4차)는 그대로다.

## §5 매니페스트

- `MainActivity`에 `<meta-data android:name="distractionOptimized" android:value="true" />`를 둔다.
- 주석 "정차 중에만 보는 화면이라 DO(주의분산 최적화)를 선언하지 않는다"는 5차 내용으로 바꾼다.
- FR-014(받아들이지 않음)면 선언은 그대로 두되 효과가 없다. verification에 적는다.

## §6 시연 장면 `live`(`scripts/demo.sh live`)

1. 시작 상태를 맞춘다: `hvac power=true`, `hvac auto=false`, `hvac driver_seat=0`, `hvac driver_temp=24`, `body front_wiper=Off`, `turn-signal mode=Off`, 조수석 비움(`seat kind=occupied&area=passenger&value=true`: 착좌는 앱에 콘솔 값의 반대로 온다)
2. 앱을 띄운 뒤 화면 오른쪽 끝 창 손잡이를 가운데로 끌어 1:1 분할(왼쪽 앱, 오른쪽 내비)을 만든다(research R2: `input swipe 2547 720 1500 720 800`). 분할이 안 되면 전체 앱 칸에서 시연한다(FR-001은 두 자리를 다 허용).
3. 기어를 D로 바꾼다. 주행거리는 넣지 않는다(고속 누적이 생기면 크루즈가 시트 열선보다 먼저 뽑힌다).
4. 와이퍼 단계를 손으로 세 번 바꾼다: Off → Low → High → Low. 바꿀 때마다 4초 간격이다(스위치 3초 읽기).
5. 10초 기다린다. 카드 "오토 와이퍼"와 음성을 확인하고 캡처한다(`live-tip1.png`).
6. 와이퍼 레버를 Auto로 바꾼다. 5초 뒤 캡처한다("써 봤어요", `live-tried.png`). 그다음 와이퍼를 Off로 내려 비를 그치게 한다(AUTO에서도 와이퍼가 돌면 비로 세어, 비 5분이 차면 뒷유리·미러 열선이 먼저 뽑힌다).
7. 방향지시등을 켠다(`turn-signal mode=BlinkLeft`). 난방을 26°로 올린다. 앱 시계 5분(실제 30초)을 기다려도 권함이 없는지 본다.
8. 방향지시등을 끈다(`turn-signal mode=Off`). 5초 안에 카드 "시트 열선"과 음성을 확인하고 캡처한다(`live-tip2.png`).
9. 기어를 P로 바꾼다. P 화면(시트 열선 안내, 말하지 않음, 위에 "오토 와이퍼, 써 보셨네요" 띠)을 캡처한다(`live-park.png`).

- 시간표(앱 시계, 실제 6초 = 1분): 1번 권함 약 2분 → Auto 약 4분 → 방향지시등 켬·난방 26° 약 4.5분 → 끔 약 9.5분 → 2번 권함 약 10분 → P 약 10.5분.
  - 비 구간(Low부터 Auto까지)은 약 3.5분이라 뒷유리·사이드미러 열선 기회(비 5분)가 생기지 않는다.
  - 주행거리를 넣지 않고 운전이 20분보다 짧아 크루즈 기회도 없다.

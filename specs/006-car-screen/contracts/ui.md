# UI 계약: 안 써본 기능 6차 — 차 화면 개선

크기 단위는 sp(글자)·dp(칸)다. 에뮬레이터에서 1dp = 1px이다. "그대로"는 지금 값을 바꾸지 않는다는 뜻이다.

## §1 공통 도우미(`Ui`, Screens.kt)

| 도우미 | 지금 | 바뀜 |
|---|---|---|
| `small(s)` | 22sp, text3, 600 | **24sp**, text3, 600 |
| `chip(label, fg, bg, icon)` | 20sp 600, 여백 18·9·20·9, 아이콘 22dp | **24sp** 600, 여백 20·10·22·10, 아이콘 **26dp**. 누르지 않는 상태 칩 전용 |
| `action(label, fg, bg, onClick)` (새) | 없음 | `chip`과 같은 글자·색에 **최소 높이·폭 76dp**, 글자 가운데, 가로 여백 28. 누르는 칩은 모두 이것을 쓴다 |
| `cardTitle(title, right)` | 26sp 600 / 오른쪽 22sp text3 | **28sp** 600 / 오른쪽 **24sp** text3 |
| `where(w, blink)` 버튼 그림 | 누를 버튼 22sp 700 흰 글자·파랑 바탕, 나머지 19sp 400 | 누를 버튼 **24sp** 700, 나머지 **22sp** 400. 색·여백·깜빡임 규칙 그대로 |
| `banner(text)` | 22sp 600 | **24sp** 600 |
| `body`, `headline` | 26sp / 48sp(인자로 44~60) | 그대로 |

## §5 뒤로 버튼과 상태 보존(`MainActivity`)

뒤로 버튼(`onBackPressed`), 위에서부터 처음 맞는 것:

1. 기록 다시 보기(`openHistory >= 0`) → 기록 목록(`openHistory = -1`), 스크롤은 `listY`.
2. 기록 목록 또는 구역 카드 → 둘 다 닫고 상황 화면.
3. 그 밖 → 지금처럼 앱을 나간다.

상태 보존:

- `onSaveInstanceState`에 넣는 값: `zone`(열린 구역 이름, 없으면 넣지 않음), `history`(openHistory, 없으면 넣지 않음), `listY`, `scrollY`(지금 스크롤), `drivesSeen`.
- `onCreate(saved)`에서 되살린다. 되살린 뒤 첫 `render`는 화면을 그리고 `scrollY`로 스크롤한다(한 번만).
- `onPause`는 `isChangingConfigurations`가 거짓일 때만 열린 칸을 닫는다.
- `render`의 "주행 중이거나 운전 수가 바뀌면 닫기"는 그대로다. 그래서 설정 변화 사이에 운전이 시작되었거나 새 결과가 생기면 칸이 닫힌다.

## §6 바뀌지 않는 것

상황 화면 우선순위(spec 용어), 기능 판단과 음성, 주행 중 다시 그리기 규칙(5차 §2), 저장 형식, 차 지도 모양과 애니메이션, 화면 여백.

세로 화면

위에 오늘의 한 가지(C), 아래에 지도(A)와 도감 목록(B)을 나란히 둬요. 세로는 폭이 좁아 근거와 버튼 그림을 작게 줄였어요.

섞은 방식

  • C 운전 직후의 주인공. 왜 권하는지(근거 타임라인)와 어디를 누르는지(버튼 그림)를 같이 보여 줘요.
  • A 기능 6개의 실제 자리. 이번 안내는 파랗게 깜빡이고, 익히면 초록으로 바뀌어요.
  • B 진행 원 1/6과 도감 카드. 지도의 점이나 목록을 누르면 그 기능의 카드가 오른쪽(세로는 위)에 열려요. 6개를 다 모으면 "도감 완성" 화면이 나와요.
